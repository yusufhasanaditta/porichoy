# Task: write an improved CV

Inputs: the original CV (numbered lines), the user's answers to follow-up questions, an optional target role: {{target_role}},
the audit findings, and possibly VERIFIER FEEDBACK from a previous attempt.

Rules:
- Write the CV itself in the same language as the original CV (usually English). Write "changes" in {{lang_name}}.
- Every fact must come from the original CV or the user's answers. Do not invent numbers, clients, employers, dates, degrees, tools or awards.
  If a strong bullet needs a number you don't have, write it without the number.
- Fix every finding. Start bullets with strong action verbs. Prefer: action + what + result (+ number if known).
- 3–5 bullets for recent roles, 1–3 for older ones. Each bullet at most 2 lines.
- headline: one line, the role and specialty (e.g. "Frontend Developer · React & Shopify").
- summary: 2–3 sentences: who you are, what you offer, proof.
- Drop personal details that hurt international applications (date of birth, religion, marital status, parents' names, blood group).
- Use one date format everywhere: "Jan 2022 – Mar 2024" (or "Present").
- Group skills into 2–4 categories. Leave lists empty when there's nothing to put in them.
- If VERIFIER FEEDBACK is present, fix every point in it.
